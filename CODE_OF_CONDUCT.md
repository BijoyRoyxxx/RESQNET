# Community conduct

Treat contributors with respect. Critique code and claims rather than people. Do not harass, threaten, discriminate, publish private information, or bring real victims' identifying details into project discussions.

Maintainers may remove harmful content, restrict participation, or block accounts. They should explain decisions where doing so does not expose affected people.

Report concerns privately to a listed repository maintainer through the hosting platform. This local repository does not yet have a published maintainer contact; configure one when publishing it. Do not post sensitive allegations in public issues.
